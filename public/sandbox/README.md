# Sandbox

Work-in-progress pieces shared for feedback.

## How to publish something

Drop the file in this folder, commit, push. That's it.

- It's served at `https://www.wearebcc.org/sandbox/<filename>`
- The index at `https://www.wearebcc.org/sandbox` lists it automatically
- For HTML files, the list title comes from the `<title>` tag — name it well
- Listed types: html, pdf, png, jpg, gif, svg, mp4, webm. Anything else
  (including this README) is still served by direct link but stays off the index

## Posture

Unlisted, not secret: `noindex` keeps these out of search, but anyone with the
link can open them. Don't put anything confidential here — gated material
belongs in `/decks`, behind the partner gate.
